Experimental release for Zotero 10 on Windows x64.

- **Faster local search.** Duplicate detection reuses normalized text and skips detailed comparisons when two passages cannot meet the similarity threshold. In two Fast-mode tests on a local index with about 2,300 chunks and the model already loaded, full local searches took **1.53–1.81 seconds**, down from **38.74–41.87 seconds**. The ranked results matched in both tests. These timings cover local retrieval only.
- **Choose a search language.** Open **Search language** below the collection selector. **Automatic** uses the indexed document languages in the selected library or collection. A manual choice limits AI and evidence queries, including tool searches, to one language. Direct search uses the terms you enter.
- **PDF processing status.** The library column shows which PDFs have been processed. Click the status icon to process an available PDF or see why it cannot be processed.

Download `Zitatlotse-0.32.0.xpi`, install it through Zotero’s add-on manager, and restart Zotero. The download includes the Windows runtime. Existing indexes and saved quotations can be used after the update.
