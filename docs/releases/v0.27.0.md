# Zitatlotse 0.27.0 — complete XPI installation

Experimental prerelease for Zotero 10 on Windows x64.

## Installation

Download **Zitatlotse-0.27.0.xpi**, install it in Zotero through **Tools → Add-ons → Install Add-on From File**, then restart Zotero.

The XPI includes Python, CPU libraries and the local search service. Zotero handles setup and startup automatically, with a progress bar. No separate Python installation or manual service launch is needed. Search models download when first used. Ollama is optional and must be installed separately for local AI.

## Included features

Local multi-stage quotation search, library/collection selection, AI chat, optional agentic calls with an activity view, supporting/opposing evidence, document relevance chart, navigation and highlighting in Zotero's PDF reader, saved quotations with notes and CSL citation styles, provider/model selection and compatible custom Hugging Face encoders. The source archive contains detailed descriptions in `docs/`.

## Changes

- Complete local runtime included in the XPI.
- Zotero handles setup, updates and service startup.
- Retry setup after failures and check service availability every 30 seconds.
- Updates preserve the index, model cache and saved quotations.
- Package setup tested without Python on the search path or API calls.

## Downloads and notes

The XPI is all you need for normal use. The project source and corresponding third-party source archives are available for review and license compliance; `SHA256SUMS.txt` contains their checksums.

Initial model setup can take time. OCR, an ANN index and automatic XPI updates are not included. Search quality needs further evaluation. A real Windows reboot still needs separate testing.
