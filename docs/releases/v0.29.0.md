# Zitatlotse 0.29.0 — navy, pink and cyan interface

Experimental release for Zotero 10.0.x on Windows x64. Install the XPI through Zotero's add-on manager and restart Zotero. Existing indexes, settings and saved quotations are preserved; no embedding rebuild is needed for this update.

- The add-on window now uses dark navy surfaces, blue gradient cards, thin slate borders and brighter typography, inspired by the supplied reference.
- Primary actions use pink gradients. Cyan highlights active tabs, keyboard focus, the chat outline and animated progress bars.
- Inputs, provider/model selectors, saved quotes, evidence panels and document relevance views share the new palette. Pro/contra and relevance-category colors retain their meanings.
- The top-right close control, responsive layout, opening/closing animation, session history and search behavior are retained. Native Zotero chrome is unchanged.
- Includes the existing hidden Windows helper startup, startup readiness correction and Normal/Fast search modes.
- Packed-XPI startup reads bundled resources through Zotero's local resource channel. A healthy worker can finish preparation even if the setup-process exit callback is delayed.
- Normal mode uses BERTScore; Fast mode skips it for direct, AI and evidence searches. Fast results may be less accurate. Existing result pages keep the mode they started with.
- Adds 14 generated-PDF/SQLite/HTTP system tests and a repeatable per-test reporting harness. The detailed catalogue explains all 127 Python test methods and remaining manual checks.

## Verification

- 123 backend test methods and 4 installation-manifest methods passed (127 total), with deterministic model/provider doubles and generated PDFs.
- All three JavaScript test programs passed: Zotero integration, window/session logic and startup orchestration.
- The exact release XPI passed integrity and source-match checks, fresh isolated setup without external Python, completion to 100%, process-loss restart and preservation of the test database.
- No cloud API calls or model downloads were made in this expanded run.

These are not real model-quality benchmarks. Native Zotero visual verification of the new theme and a real Windows reboot remain pending. Existing screenshots show the previous interface. See [test status](../STATUS.md) and the [testing guide](../TESTING.md).
