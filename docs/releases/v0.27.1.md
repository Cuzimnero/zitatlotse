# Zitatlotse 0.27.1 — installation fix

Experimental prerelease for Zotero 10 on Windows x64.

## Fixed

Version 0.27.0 removed the `applications.zotero.update_url` field during publication. Zotero requires this field even when installing an XPI manually. The missing field caused the generic "may be incompatible" installation error, despite the correct Zotero version range.

Version 0.27.1 restores the field with a real HTTPS update endpoint. The endpoint is a valid empty update feed; automatic upgrades are not offered yet. The add-on ID and Zotero compatibility range remain the same.

Packaging now rejects manifests missing Zotero's required installation fields. Regression tests cover the omitted update URL, missing version bounds and placeholder endpoints. Service health and runtime checks use the corrected release version.

## Install

Download **Zitatlotse-0.27.1.xpi**, choose **Tools → Plugins → Install Plugin From File** in Zotero and select the downloaded XPI. Restart Zotero when prompted. Use this file instead of the rejected 0.27.0 package.

The XPI includes the Windows x64 runtime and local search service. Model weights download on first use. Existing library data, saved quotations and model caches are preserved by the installer.

The source archive, corresponding third-party sources and `SHA256SUMS.txt` are included for review and license compliance. Original project code is MIT; external components retain their own licenses. Search quality and other previously documented prototype limitations are unchanged.
