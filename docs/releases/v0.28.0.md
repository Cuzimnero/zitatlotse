# Zitatlotse 0.28.0 — local search-speed candidate

This candidate has not been published. It includes the 0.27.2 startup correction.

## Search speed setting

Settings now offers:

- **Thorough – with BERTScore** (default): existing cosine selection and BERTScore reranking.
- **Fast – without BERTScore (may be less accurate)**: cosine-only ranking with no BERTScore loading or inference. The UI warns about lower possible accuracy and more irrelevant matches.

The selection saves automatically for new direct, AI and evidence searches, including agent tool calls and fallback searches. AI review stays enabled when configured. Existing result pages retain their original mode. No reindexing or embedding-model change is required. German/English labels follow the existing Zotero locale behavior.

## Verification

- Backend tests cover skipping BERT completely, default thorough behavior, saved settings, scope, empty selection, PDF locations and mode-preserving pagination.
- UI tests cover labels, saving, reopening and restoring thorough mode.
- An isolated HTTP integration test uses real E5 embeddings, real BERTScore, synthetic PDFs and a separate database/settings file. Both modes find the expected passage; fast mode leaves the BERT scorer unloaded. No cloud requests or model downloads are made.

Fast mode is a latency/accuracy trade-off, not a quality guarantee. Its cosine scores should not be compared directly with the mixed scores in thorough mode. AI calls and full evidence assessment can still take significant time.
