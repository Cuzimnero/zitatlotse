# Zitatlotse 0.28.3 — hidden startup and header styling

Local candidate, not published or installed automatically.

- Windows helpers now use the native Zotero/Gecko `nsIProcess.startHidden` and `noShell` flags before process creation. The PowerShell `-WindowStyle Hidden` argument remains as an additional measure. This also applies to cached Python background starts. No Windows security settings are changed.
- The search-window header uses the existing logo in a translucent tile and a larger, heavier wordmark. The purple theme and top-right close control remain in place.
- Both search-speed modes and the startup-readiness correction remain included.

The native flags are supported and used by components shipped in the installed Zotero runtime. Startup regression checks require them for setup and cached-runtime launches; startup, plugin and search-window test programs pass. Native visual verification of this new candidate still requires installation by the user.
