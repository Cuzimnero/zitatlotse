# Zitatlotse 0.27.2 — local startup test candidate

This candidate is provided locally for user testing before publication.

## Startup fix

The packed add-on tried to read its runtime manifest and setup script using `Zotero.HTTP.request`. In the installed XPI path, `quote-search@local.example.xpi`, Zotero's HTTP helper tries to access `nsIURI.username` and fails with `NS_ERROR_FAILURE` before the setup process starts.

The candidate uses `Zotero.File.getResourceAsync`, Zotero's local resource channel, for these bundled files. Failed metadata reads are no longer cached permanently, so a later retry can recover.

A regression test now uses an installed XPI path containing both a space and `@`, reproduces the HTTP helper failure and checks resource-read retry. The add-on identifier, supported Zotero versions and database format remain the same.

## Installation

Install the supplied **Zitatlotse-0.27.2.xpi** through Zotero's plugin manager and restart Zotero when prompted. This candidate has not been uploaded to GitHub.

See the accompanying local feature-test report for the checks performed and their limitations.
